## 1. Scientific objective and boundaries

Describe the uniquely resolved primary-tumor RNA-seq STAR Counts source universe from GDC CPTAC-3. Verify the technical representation of unstranded gene counts; account for additional same-case RNA files; and reconcile a bounded twelve-output STAR-to-upstream-input GDC metadata sample at exact case/aliquot level.

The audit does not establish TCGA lineages, assign QC PASS/FAIL, approve a patient for external inference, select an alternative source specimen based on counts, compute or refit any transcriptomic program, infer drug resistance or donor independence, or claim external structural replication.

## 3. Primary source candidates and count audit

The 111 primary RNA file inventory contains 1,731 provisional primary files across 1,370 cases. Identify 1,082 cases with exactly one primary STAR file, sample and aliquot. Preserve the remaining 288 multiply represented cases outside the main technical inventory; do not rescue or collapse multiple specimens by quality or transcriptomic outcomes.

For the 1,082 candidates, read the local `gene_id` and `unstranded` columns and record: gene rows, special STAR rows, duplicate version-normalized Ensembl gene IDs, nonnegative-integer count validity, invalid values, assigned gene-count total, number of detected genes, special-category tallies and same-case RNA ancestry flags.

The previously executed source inventory contains 1,082 valid count vectors with no invalid gene values; the 112 audit does not apply exclusion thresholds or establish QC PASS. The inventory is **not** equivalent to normalized expression, read-level alignment QC or frozen-program gene coverage (assessed by Notebook 113).

## 4. Provider metadata provenance

Construct an outcome-blind, deterministic twelve-file metadata sample: three uniquely represented STAR outputs per each of four GDC `primary_site × disease_type` source contexts, selected by fixed count rank and file-ID ordering. Reconcile the selected STAR identifiers with the immutable output metadata snapshot.

Require a direct GDC STAR file/aliquot association consistent with Notebook 111. Resolve a single input file UUID from each STAR workflow metadata node. Authenticate the second source snapshot against that exact UUID set and its stored query digest. Compare each upstream input's directly reported case and aliquot to the STAR output's; do not infer matches from cases alone.

Compare six provider fields — `total_reads`, `proportion_reads_mapped`, `proportion_reads_duplicated`, `average_base_quality`, `average_read_length`, `average_insert_size` — between embedded workflow and direct GDC input file projections. The executed audit observed 12/12 exact source associations and 72/72 concordant values. Such agreement is **provider metadata consistency**, not an independent sequencing-quality measurement. It does not validate denominators, workflow versions, library composition or QC thresholds.

This targeted twelve-file sample is not randomly representative of CPTAC-3; its results must not be extrapolated to all 1,082 candidates.
