# Analysis contracts

An analysis contract is prospective: it freezes relevant analytical decisions
before inspection of the corresponding results.

A completed contract may receive a clearly labeled retrospective
execution/freeze addendum, but its prespecified analytical rules must not be
rewritten as though they were authored after execution. Retrospective
implementation or closure records and prospective analysis contracts are
distinct document types.

Do not create retrospective “prespecified contracts” for historical notebooks
completed without one. Not every notebook requires a contract; they are most
appropriate where result-contingent flexibility could affect the inferential
universe, eligibility, thresholds, multiplicity, evaluation design, leakage
controls, replication or rescue rules, or related methodological choices.
