# Pan-Cancer Epigenetics Framework

## Operational Analysis Roadmap (v3.0)

### Project Objective

Identify recurrent epigenetic-transcriptomic programs across human cancers through independent discovery in primary tumors and cancer cell models, and characterize their associated functional vulnerabilities, pharmacogenomic contexts, and perturbational hypotheses.

---

# Scientific Positioning

This project is designed as a computational oncology framework focused on:

* recurrent epigenetic-transcriptomic program discovery,
* cross-system reproducibility,
* functional characterization,
* pharmacogenomic association mapping,
* perturbational hypothesis generation.

The framework does **not** aim to:

* support clinical prediction directly from patient cohorts,
* infer biological causality from observational data,
* establish validated targets,
* claim therapeutic efficacy from in silico analyses,
* reconstruct adaptive evolutionary trajectories.

All findings should be interpreted as computational associations requiring further validation.

# Repository Architecture Principles

## Data Storage Philosophy

### Raw Data

Raw data remain immutable and organized by source dataset.

```text
data/raw/

depmap/
gdsc/
ctrp/
prism/
tcga/
lincs/
cell_model_passports/
...
```

### Interim Data

Interim data contain harmonized and analysis-ready datasets that serve as consumable inputs for downstream notebooks.

```text
data/interim/

metadata/
expression/
methylation/
dependencies/
pharmacology/
perturbational/
qc/
```

### Processed Data

Processed data contain stable biological entities and analytical outputs generated by the framework.

```text
data/processed/

tumor_programs/
cellline_programs/
consensus_programs/
functional_vulnerabilities/
pharmacogenomic_contexts/
perturbational_hypotheses/
validation/
```

### Scientific Results

Publication-ready outputs are organized by manuscript.

```text
results/

paper1/
paper2/
supplementary/
```
